# 안전 스마트 창문 시스템

임베디드 시스템 창업 경진대회 출품을 위한 안전 스마트 창문 시스템입니다.
실내외 환경 정보와 창문 상태를 확인하고, 비·미세먼지·바람 등 환기에 불리한 상황을 고려해 창문 개폐를 제어하는 것을 목표로 합니다.

## 개발 배경

일상적인 환기는 실내 공기질 개선에 필요하지만, 사용자가 항상 날씨와 공기질을 확인해 창문을 조절하기는 어렵습니다.
특히 외출 중 비가 오거나 미세먼지가 나빠지는 상황에서는 창문을 제때 닫지 못해 불편과 안전 문제가 발생할 수 있습니다.

이 프로젝트는 센서 노드, 모터 노드, 모바일 앱을 연동해 창문 상태와 주변 환경을 한눈에 확인하고 필요한 조작을 빠르게 수행할 수 있도록 설계했습니다.

## 주요 기능

- 실내 센서 데이터를 이용한 온도, 습도, 미세먼지 상태 확인
- 위치 기반 실외 날씨, 강수량, 풍속, 풍향, 미세먼지 정보 확인
- 모터 노드를 통한 창문 열기, 닫기, 정지, 개도율 지정 제어
- 자동 모드에서 실내외 환경과 주거 정보를 바탕으로 권장 개도율 계산
- 비 감지 또는 모터 오류 상황에서 보호 상태 표시
- BLE 프로비저닝을 통한 장치 초기 연결
- MQTT over TLS 기반 장치 상태 수신 및 명령 전송

## 시스템 구성

```text
Flutter 앱
  └─ MQTT 브로커
      ├─ ESP32-C3 모터 노드
      │   └─ TB6600 스텝모터 드라이버 기반 창문 개폐 제어
      └─ ESP32-C3 센서 노드
          ├─ PM2008M 미세먼지 센서
          └─ BME280 온습도·기압 센서
```

## 동작 흐름

1. 사용자가 앱에서 서비스 계정과 장치를 연결합니다.
2. 센서 노드는 실내 환경 데이터를 측정해 MQTT로 전송합니다.
3. 앱은 센서 데이터와 위치 기반 실외 날씨 정보를 함께 표시합니다.
4. 사용자는 앱에서 창문을 열기, 닫기, 정지하거나 원하는 개도율을 입력합니다.
5. 모터 노드는 MQTT 명령을 수신해 창문을 제어하고 최신 상태를 다시 전송합니다.
6. 자동 모드에서는 강수량, 풍속, 미세먼지, 온습도 차이를 반영해 권장 개도율을 계산합니다.

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 펌웨어 | ESP-IDF, C++ |
| 제어 보드 | ESP32-C3 |
| 센서 | PM2008M, BME280 |
| 모터 제어 | TB6600 스텝모터 드라이버, FastAccelStepper |
| 앱 | Flutter, Riverpod |
| 통신 | BLE 프로비저닝, MQTT 5 over TLS |

## 프로젝트 구조

```text
firmware/
  main/      모터 제어 펌웨어
  sensor/    실내 환경 센서 펌웨어
  common/    공통 장치, MQTT, BLE 프로비저닝 컴포넌트
  sdk/       Flutter 앱에서 사용하는 장치 SDK
software/    Flutter 앱
```

## 실행 방법

### Flutter 앱

```bash
cd software
flutter pub get
flutter run
```

### 펌웨어 빌드

ESP-IDF 6.0.2 환경에서 각 펌웨어 폴더로 이동한 뒤 빌드합니다.

```bash
cd firmware/main
idf.py -B build build
```

```bash
cd firmware/sensor
idf.py -B build build
```

## 기대 효과

- 사용자가 날씨와 공기질을 직접 확인하지 않아도 창문 상태를 편리하게 관리할 수 있습니다.
- 비, 강풍, 미세먼지 상황을 고려해 창문을 제어함으로써 실내 환경 악화를 줄일 수 있습니다.
- 센서 노드와 모터 노드를 분리해 설치 환경에 맞게 확장하기 쉽습니다.
- 앱 기반 제어로 임베디드 장치의 상태 확인과 사용자 조작성을 높일 수 있습니다.
